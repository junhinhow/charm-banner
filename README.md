# charm-banner  ASCII art banner generator for terminal UIs ÔÇö styled with [Lip Gloss](https://github.com/charmbracelet/lipgloss).  > [Leia em Portugu├¬s](README.pt-br.md)  ## Features  - Convert text to large ASCII art using Unicode block elements (`ÔûÇÔûäÔûê`) - Three built-in font sizes with **square glyphs**: **Small** (3├ù3), **Medium** (5├ù5), **Large** (7├ù7) - Full [Lip Gloss](https://github.com/charmbracelet/lipgloss) styling support - Supports letters A-Z, digits 0-9 and common punctuation (`! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { | } ~`) - Accented letters (`├ü ├Ç ├é ├â ├ä ├ë ├è ├ï ├ì ├Ä ├Å ├ô ├ö ├ò ├û ├Ü ├ø ├£ ├ç ├æ` ÔÇª) reuse the glyph of their base letter - Characters that are not part of the font are drawn as a space  ## Install  ```bash go get github.com/junhinhow/charm-banner@latest ```  ## Usage  ```go package main  import (     "fmt"      banner "github.com/junhinhow/charm-banner"     "charm.land/lipgloss/v2" )  func main() {     // Simple banner     fmt.Println(banner.Render("HELLO"))      // With font size     fmt.Println(banner.Render("GO", banner.WithFont(banner.Large)))      // With Lip Gloss styling     style := lipgloss.NewStyle().         Foreground(lipgloss.Color("#FF79C6")).         Bold(true)     fmt.Println(banner.Render("CHARM", banner.WithStyle(style))) } ```  ## API  | Function | Description | |----------|-------------| | `Render(text string, opts ...Option) string` | Render text as ASCII art banner | | `WithFont(Font) Option` | Set font size: `Small`, `Medium`, `Large` | | `WithStyle(lipgloss.Style) Option` | Apply a Lip Gloss style to the output |  ## Notes  - `Render("")` returns an empty string. - Every character of the input occupies exactly `font width` columns (3, 5 or 7) and the lines of   a banner always have the same width. - The text is normalized before rendering: lowercase letters become uppercase and accented   letters fall back to the base letter (`"├ü"` is drawn exactly like `"A"`).  ## License  [MIT](LICENSE)  <!-- 2026-01-11 09:00:00 -
